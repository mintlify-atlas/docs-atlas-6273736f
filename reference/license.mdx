## What This Means for You

<AccordionGroup>
  <Accordion title="Using Laravel in Your Projects">
    You can freely use Laravel in any project:
    
    - Personal projects
    - Commercial applications
    - Open source projects
    - Proprietary software
    - Client work
    - SaaS products
    
    <Info>You don't need to ask permission, pay royalties, or release your source code.</Info>
  </Accordion>

  <Accordion title="Modifying Laravel">
    You're free to modify Laravel to fit your needs:
    
    - Customize the framework
    - Add new features
    - Remove unused components
    - Adapt it for specific use cases
    
    <Note>Modified versions should still include the original MIT license notice.</Note>
  </Accordion>

  <Accordion title="Distributing Laravel">
    You can distribute Laravel or applications built with Laravel:
    
    - Share your modifications
    - Package Laravel in your products
    - Bundle Laravel with your software
    - Redistribute to clients
    
    <Info>When redistributing, include a copy of the MIT license and copyright notice.</Info>
  </Accordion>

  <Accordion title="Attribution Requirements">

    - Include the MIT license text
    - Preserve the copyright notice
    - Include these in all copies or substantial portions

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Can I use Laravel in commercial projects?">
    **Yes, absolutely.** The MIT License explicitly allows commercial use. You can build and sell applications using Laravel without paying royalties or fees.
  </Accordion>

  <Accordion title="Do I need to open source my Laravel application?">
    **No.** The MIT License does not require you to release your source code. Your application code remains your property.
  </Accordion>

  <Accordion title="Can I remove Laravel branding?">
    **Yes.** You're not required to display Laravel branding, logos, or "powered by" notices in your applications.
  </Accordion>

  <Accordion title="Can I sell Laravel-based products?">
    **Yes.** You can create and sell products built with Laravel. Many SaaS companies and commercial products are built on Laravel.
  </Accordion>

  <Accordion title="Do I need permission from Taylor Otwell?">
    **No.** The MIT License grants permission to everyone. You don't need to ask for specific permission to use Laravel.
  </Accordion>

  <Accordion title="What if I modify Laravel's core?">
    **You can.** You're free to modify Laravel. If you redistribute your modifications, include the original MIT license.
  </Accordion>
</AccordionGroup>
